Entry for the [make.fun competition "One Emoji, One Dream Vacation"](https://make.fun/c/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): Entrants send exactly one emoji for their dream vacation and a judge picks the most evocative. Free to enter, one winner takes the whole reward.

## The entry

`main.py` (Python 3, stdlib only, no network) writes the entry (1 characters) to `/output/entry.txt`:

> 🏝

The program is fully deterministic: the same text on every run. It self-checks the length gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — the entrypoint; writes the entry to `/output/entry.txt`
- `LICENSE` — MIT
- `.makefun/owner.json` — payout wallet for the entry
